## Abstract

Reports on agentic AI methods have to show things a printed paper cannot: a model's output as it was generated, a conversation, a figure that moves, a control the reader can turn. This specimen shows each of those in the Vivid Insights report format, using one small example throughout. The example is a normative model in the sense of @caut2025: a rule that turns a z-score into one of seven phrases using six thresholds. We show the rule as an equation, a figure, a video and an interactive figure, and we quote one text generated by a wordalisation app word for word from the file it was saved in. The specimen makes no empirical claim. It is there so that an author can see what each part of a report looks like before writing their own.

## Introduction

A patient whose systolic blood pressure is 110 mmHg is told, in one generated text, that this "strongly lowers your risk". Somewhere between the measurement and that sentence, a person chose where "strongly" begins. @caut2025 call the rules that make such choices a normative model, and they argue that writing those rules down is what makes a generated text checkable.

Reports about methods like this need more than prose and static figures. A reader has to see the generated text exactly as it came out, follow a conversation with a converser, and often try the method for themselves. The Vivid Insights report format puts all of these in one page that reads like a paper and can be printed as one.

We use a single small example throughout. We ask three things of it:

1. How does a fixed set of thresholds divide a population into described groups?
2. What does a reader see when one value moves across the thresholds?
3. How does the description change when one threshold is moved?

## Method {#sec-method}

### The normative model

We describe a value $x$ by its z-score,

$$
z = \frac{x - \mu}{\sigma}
$$ {#eq-z}

where $\mu$ and $\sigma$ are the mean and standard deviation of the population the value is compared with. The normative model maps $z$ to one of seven phrases, from "far below average" to "far above average", using cut points at $\pm 0.5$, $\pm 1$ and $\pm 2$.

::: definition {#def-normative title="Normative model"}
The rules that turn the output of a statistical model into words: which thresholds separate one phrase from the next, what a value is compared with, and how the comparison is worded [@caut2025].
:::

The cut points are choices. We picked them so that the middle phrase covers the central 38% of a standard normal population, and so that the outer phrases are reserved for values more than two standard deviations from the mean. The function `words()` in `Code/fig_thresholds.py` is the model, and every figure below calls it.

### The generated text

The generated text we quote in @sec-quoted-output comes from the app built for the article by Zenebe and colleagues on communicating individual health risk. That app uses a normative model of the same kind on the contributions of a logistic regression, and passes the resulting synthetic text to a large language model. We did not generate any text for this specimen.

### One value moving

In @fig-sweep a single value moves from $z = -2.8$ to $z = 2.8$. The phrase above the curve is what `words()` returns at each position. A video shows the moment the description changes, which a still figure can only list.

### Moving a threshold

@fig-explorer lets the reader move the value and the inner cut point. Setting the inner cut to 0.8 and the value to 0.74 changes the description from "slightly above average" to "average" with no change in the data.

::: interactive {#fig-explorer src="interactives/threshold-explorer/index.html" height=370 fallback="Code/outputs/figures/thresholds.png" title="Threshold explorer"}
Interactive version of @fig-thresholds. The upper slider sets the value; the lower one sets the inner cut point, which is $\pm 0.5$ in the rest of this specimen. The other four thresholds stay at $\pm 1$ and $\pm 2$.
:::

## Discussion

A normative model with fixed cut points gives the same words to everyone in a band, so a value of 0.51 and a value of 0.99 are both "slightly above average" while 0.49 is "average". @fig-explorer shows how much that boundary depends on one choice. Writing the thresholds down, as in @def-normative, is what lets a reader of a generated text find out where its words came from.

The quoted output in @sec-quoted-output shows the same thing in a real application. "Strongly lowers your risk" is a threshold crossed in the app's normative model, and the reader of the text has no way to see it unless the model is published alongside.

## Limitations

The example is deliberately small. Its thresholds were chosen to illustrate the format and were not tested on readers, and the share of the population in each band assumes a normal distribution. The quoted output comes from another project and was not evaluated here.
